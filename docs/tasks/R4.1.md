## Qué entra (`grun/server.py`)

- `make_server(port, app)`: bind **solo** a `127.0.0.1`; `port=0` = puerto libre; `OSError` → `serve.port_busy`.
  Un host que no sea local → `net.non_local_host` (misma regla que `grun/ollama.py`).
- Antes de cualquier ruta y método: `Host` ∈ {`127.0.0.1:<port>`, `localhost:<port>`} si no 403 `api.bad_host`;
  `Origin` si existe = `http://<host>` si no 403 `api.bad_origin`; `Sec-Fetch-Site` ∈ {`same-origin`, `none`} si
  existe, si no 403 `api.bad_origin`.
- `status_for(code, extra=None)`: orden servidor(500) → exacto → prefijo → `.bad_` → sufijo → 500; `extra` es la
  tabla de la aplicación (gimg pasa la suya: las de imagen no entran en `grun`). Genéricos: `api.*`, `queue.*`
  (`unknown`/`batch_not_found` 404; `not_cancellable`/`not_movable`/`not_running`/`bad_state` 409; `bad_move`/
  `bad_progress` según gimg), `serve.*`, `net.*`.
- Cuerpo de error `{"error": {code, params, errors?, message}}` con `queue.make_error` / `i18n`.
- Rutas de cola (forma como gimg, invariante 13): `GET /api/queue?state=` (cabecera `X-Queue-Paused`),
  `GET /api/queue/{id}/preview`, `POST /api/queue/{id}/cancel|move`, `POST /api/queue/batches/{id}/cancel|move`,
  `POST /api/queue/pause|resume|clear`; `GET /api/health` → `{ok, api, version, pid, port, paused, worker}`.
- `Server.add_route(method, pattern, handler)` para que la aplicación ponga las suyas; las pantallas no entran.
- `serve.lock` (flock, una instancia por aplicación) y `<data>/serve.json` (0600; pid, port, url, version,
  startedAt), sin borrar nunca el candado (invariante 5).
